# Bundled fonts

Unmodified variable TrueType fonts, distributed under the accompanying SIL Open Font License files. Fonts are not covered by the library's MIT license.

Source: `google/fonts` commit `205859f680703e449fe05dce0f792cc041d6dc89`.

- [Roboto source](https://github.com/google/fonts/tree/205859f680703e449fe05dce0f792cc041d6dc89/ofl/roboto): `Roboto[wdth,wght].ttf` → `Roboto.ttf`; license `Roboto-OFL.txt`.
- [Noto Sans JP source](https://github.com/google/fonts/tree/205859f680703e449fe05dce0f792cc041d6dc89/ofl/notosansjp): `NotoSansJP[wght].ttf` → `NotoSansJP.ttf`; license `NotoSansJP-OFL.txt`.

CSS aliases `GForce Roboto` and `GForce Noto Sans JP` do not alter the font binaries. No `local()` source is used. The complete Japanese font is retained for offline and arbitrary Japanese filenames, rather than silently dropping glyphs through a demo-only subset.
