Accordion

Native details／summaryを使用します。重要情報や主要操作を閉じた状態にしません。

Tailwind CSSは必須ですか？
配布CSSはビルド済みなので実行時には不要です。Tokenやコンポーネントを変更して再ビルドする場合だけTailwind CSS v4を使用します。
ReactやVueでラップできますか？
DOM契約とdata属性を維持すれば可能ですが、ライブラリ本体は標準HTMLとVanilla JavaScriptだけで動作します。
Google公式ライブラリですか？
いいえ。Googleの公開Material Design／Workspaceガイドを参照し、業務Webアプリ向けに独自実装した非公式ライブラリです。
